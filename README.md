# Back in Time — Chapter 2 (Playable HTML Prototype)

This repository contains a browser-playable prototype of "Back in Time — Chapter 2" with simple puzzle hotspots, player movement, health, a flashlight stun, sprint, and a few puzzle types (Simon Says, Drag Cables, Bomb Disable). Use this prototype as a foundation — replace assets and expand puzzle logic to match your full game design.

Open index.html in a modern browser to play.
